Trae solo，初体验

胡守谦 · 2025-07-29 · 4 分钟

在某一个月黑风高的傍晚，知道了 trae 出新玩意了，还得是高贵的 pro 用户才能体验，刚好上个月自动续费的 pro 没到期，正好可以体验一波。。。

结果一打开天塌了，这 tmd，得等个三小时不能睡觉。。。

不辱使命也是 到手了，结果给熬虚了，过了几天 才开整。。。

打开 IDE，该说不说 logo 有够绿的，切换到 solo 模式，准备开干！

既然主打简单，那就来个 比较简单的自然语言描述，让模型自由发挥 试试看了

prompt:“帮我开发一个情侣甜蜜记录网站，支持上传互动图片，留存一切美好回忆以及规划方案，美观便捷，友好易上手，体验感拉满。”

这个感觉看着还行，但是我想着 能不能更精细化一点，有点小创新，于是又自己添加了一段，看看指令遵循怎么样

prompt:” 开发一个情侣甜蜜记录网站，解决情侣关系中缺乏新鲜感和话题的问题。核心功能包括： 情感标签与心情记录：为每个回忆添加情感标签，并基于标签推荐相关活动或话题。 智能推荐系统：根据情侣的历史记录和情感标签推荐适合的活动、目标或话题，保持互动新鲜感。 情侣共同目标与规划：提供目标管理、纪念日提醒、愿望清单等，展示目标进度。 实时互动：增加评论、点赞和分享功能，增加互动和参与感。 情侣档案与个性化数据：展示恋爱天数、目标完成情况、回忆数量等统计数据，并提供个性化设置。 隐私保护：所有数据加密存储，提供隐私设置和云备份功能。 技术要求： 使用 React 框架，结合 Firebase 进行实时数据存储与互动。 实现 D3.js 或 Chart.js 进行数据可视化。 数据加密存储与传输，确保用户隐私。 “

我觉得一个不错的亮点，就是他在这方面没有无条件遵循我的意见，而是对自己有清醒认知，不会盲目的去舔用户，然后用自己不懂的技术来造一堆伪代码出来，这是个不错的点。

由于不懂前端，有很多环境没有，也是磕磕绊绊的自己装好了，效果如下：

可以看到，虽然界面是好了，排版也没什么问题，但是这个美观度，属实是有点 抽象啊，，，老花眼远看是真看不清。。。只能说 某些方面能力有待加强

于是改造了一下，看着好歹 没那么难受了

这个时候呢，我突然想到抖音小火苗有那种小宠物，我也想来一个，于是 一言难尽的一幕来了

可能 prompt 写好点，也能正常吧，但是主打自然语言，确实是还是有点 奇怪

咱也没啥审美要求，差不多功能可以，就直接部署

然后就这么水灵灵的部署了？？？我直接十万个为什么。。。

然后一分析，App.css 文件被截断了，导致 CSS 解析错误。赶紧让 ai 修复一波，于是呢 终于也是看着是那么回事了

链接送上：https://traezy7dyk-cbsyy-bing-lus-projects.vercel.app/

感兴趣的朋友可以瞅一瞅 嘻嘻

总的来说，体验下来发现，其实也并没有完全平替，解决问题的话依然是需要 人工兜底的，不过部署个 blog 玩玩倒是绰绰有余的，全面的指令固然可以有很好的效果，但如果简单的口语表达也能做到完美胜任，这才是我们所追求的 智能吧
